# Chance

A Risk-style strategy game in the browser: solo against AI, pass-and-play, or online rooms with chat.

**Play:** https://junkyardbadger.github.io/chance/

This repo holds only the built game, served by GitHub Pages. Online rooms use Chance's own Firebase project (`chance-game-b8bc9`); its web config in `firebase-config.json` is public by design, and access is limited by the Firestore security rules.
